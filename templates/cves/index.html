CVE findings

Vulnerabilities keyword-matched from the National Vulnerability Database against discovered services. Treat each match as a hypothesis until confirmed on the host.

Remediation workflow

Prioritise and validate

  • NVD — authoritative CVSS, references, CWE mappings.
  • CISA KEV — confirms active exploitation and federal deadlines.
  • MITRE CWE — weakness types per CVE.

Patch and verify

  • Apply vendor / OS updates (apt, dnf, Windows Update, vendor portals).
  • Rescan with authenticated tools (Nessus, OpenVAS, Qualys) to map CVEs to installed versions.
  • Use compensating controls (WAF, segmentation, least privilege) when patching is delayed.
